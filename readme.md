# 🌾 my_agro_project

**my_agro_project** — это Streamlit-приложение для расчёта и планирования агробизнеса. Оно помогает пользователю рассчитать экономику выращивания культур, сохранять расчёты в локальной базе данных, получать прогноз погоды и искать актуальные цены с помощью ИИ.

## 🛠 Требования

- **Python 3.10+** (рекомендуется 3.11 или новее).
- **pip** (менеджер пакетов Python).
- Доступ к интернету для работы геокодера, погодного API и Gemini (если используется).

Все зависимости перечислены в файле `requirements.txt`.

## 📦 Установка

1. **Клонируйте репозиторий**:

   ```bash
   git clone https://github.com/ElizaLobanova/my_agro_project.git
   cd my_agro_project
   ```

2. **Создайте и активируйте виртуальное окружение** (рекомендуется):

   ```bash
   python -m venv .venv
   source .venv/bin/activate      # Linux / macOS
   # или
   .venv\Scripts\activate         # Windows
   ```

3. **Установите зависимости**:

   ```bash
   pip install -r requirements.txt
   ```

   > В `requirements.txt` уже зафиксированы все необходимые библиотеки, включая `streamlit`, `geopy`, `google-genai`, `pydantic` и другие.

## ⚙️ Конфигурирование

Приложение использует два способа задания конфиденциальных параметров: через **файл секретов Streamlit** (рекомендуется) или через **переменные окружения**.

### Файл секретов Streamlit

В репозитории есть шаблон `.streamlit/secrets.toml.example` со следующим содержимым:

```toml
# .streamlit/secrets.toml.example
GEMINI_API_KEY = "ВАШ_КЛЮЧ_ЗДЕСЬ"
```

**Чтобы настроить приложение:**

1. Скопируйте шаблон в файл `secrets.toml` в той же папке `.streamlit/`:

   ```bash
   cp .streamlit/secrets.toml.example .streamlit/secrets.toml
   ```

2. Откройте `.streamlit/secrets.toml` и замените `"ВАШ_КЛЮЧ_ЗДЕСЬ"` на ваш реальный API-ключ Gemini.

   ```toml
   GEMINI_API_KEY = "ваш_реальный_ключ_здесь"
   ```

> **Важно:** файл `secrets.toml` уже добавлен в `.gitignore` и не будет закоммичен в репозиторий. Никогда не публикуйте его.

Приложение сначала пытается прочитать ключ из `st.secrets["GEMINI_API_KEY"]`, и только если его там нет — переключается на переменную окружения.

### Переменные окружения (альтернатива)

Если вы не хотите использовать `secrets.toml`, можно задать ключ через переменную окружения перед запуском:

```bash
export GEMINI_API_KEY="ваш_реальный_ключ_здесь"   # Linux / macOS
# или
set GEMINI_API_KEY=ваш_реальный_ключ_здесь        # Windows (cmd)
```

В коде предусмотрен фолбэк на `os.environ.get("GEMINI_API_KEY")`, поэтому этот способ полностью работоспособен.

## 🗄 База данных

Приложение использует **локальную базу данных SQLite** с именем `agro_data.db`. Файл базы данных создаётся автоматически при первом запуске — никаких дополнительных действий по инициализации не требуется.

Функция `init_db()` в `db_manager.py` создаёт все необходимые таблицы (`users`, `calculations`, `expense_overrides`, `custom_expenses`, `risk_checks`, `expense_items`, `dismissed_items`), если они ещё не существуют.

> Файл `agro_data.db` уже присутствует в репозитории, но при необходимости вы можете удалить его — при следующем запуске он будет создан заново со всеми таблицами.

## 🚀 Запуск приложения

После установки зависимостей и настройки секретов выполните:

```bash
streamlit run app.py
```

Streamlit запустит локальный веб-сервер и откроет приложение в браузере (по умолчанию — `http://localhost:8501`).

## 🔌 Примечания по внешним API

- **Gemini API** — требуется ключ `GEMINI_API_KEY`. Без него приложение всё равно запустится, но функции, связанные с ИИ-поиском цен, будут недоступны (в коде предусмотрена проверка `GENAI_AVAILABLE`).
- **Open-Meteo** — прогноз погоды запрашивается без ключа, API открытый.
- **Nominatim (OpenStreetMap)** — геокодирование региона также не требует ключа; используется с таймаутом и кэшированием.
